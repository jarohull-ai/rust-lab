# Support

Rust Lab is maintained as an open-source public alpha. Community support is best-effort.

## Where to ask

- **Bug:** open a GitHub issue using the bug report form.
- **Feature proposal:** use the feature request form and describe the user problem first.
- **Usage question:** open a GitHub Discussion when Discussions are enabled; until then, use a
  clearly labelled question issue.
- **Security issue:** follow [SECURITY.md](SECURITY.md), never a public issue.

Before reporting a problem, run `./scripts/verify.sh`, check the requirements in the README, and
review [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md). Include Rust, Node.js, operating system,
and sandbox backend information. Remove credentials, personal paths, and private source code from
logs.

The supported alpha host is Linux. Windows, macOS, hosted multi-user deployments, private GitHub
repositories, and crates.io publishing are not currently support commitments.
